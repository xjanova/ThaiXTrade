> เงินขายเข้าพูล IDTC/USDT ทั้งหมด และ LP ล็อกไว้ 12 เดือนหลังจบการขาย

**ใครทำอะไร**

ทุกขั้นต้องตรวจบนเชนให้ผ่านก่อนไปขั้นถัดไป ถ้าขั้นไหนไม่ผ่าน ให้หยุดตรงนั้น

## 3. 🤖 ตรวจ + ลงทะเบียนสัญญากับเว็บ

## 4. 🤖⛔ กระเป๋าตัวแทนขาย (sale agent) บนเซิร์ฟเวอร์

- **กระเป๋านี้ทำอะไร:**
  - รับ USDT_TPIX ที่สะพานมิ้นต์ให้
  - ซื้อแทนผู้ซื้อด้วย `buyFor` แล้ว IDTC ลงกระเป๋าผู้ซื้อโดยตรง
  - ถ้าซื้อไม่ได้ จะคืน USDT_TPIX ให้ผู้ซื้อ
- **กระเป๋านี้ไม่ทำอะไร:**
  - ไม่ถือ IDTC
  - ไม่มีสิทธิ์ในสัญญาขาย
  - ไม่ต้องเติมแก๊ส (เชน TPIX = 0)
- **ขั้นตอน:**
  1. สร้าง keystore ใบใหม่ (ไม่ใช้ใบเดียวกับสะพาน) ที่ `/home/admin/.tpix/launchpad-agent.keystore.json` (โฟลเดอร์ 700 ไฟล์ 600)
  2. เขียน passphrase ลง `.env` โดยตรง ไม่ผ่านแชท แล้วสำรอง `.env` ก่อนแก้
  3. ตั้ง `LAUNCHPAD_AGENT_KEYSTORE`, `LAUNCHPAD_AGENT_PASS` และ `LAUNCHPAD_SOURCE_CHAINS=56` แล้วรัน `php artisan config:cache`
  4. ทดสอบว่าถอดรหัสได้ แล้วจดที่อยู่กระเป๋าตัวแทนไว้

## 6. 👤 เปิดขาย IDTC บนเชน

```powershell
cd D:\Code\TPIX\TPIX-Coin\contracts
.\scripts\launchpad-create.ps1
```

**สคริปต์จะถาม:**
1. วันเวลาเปิดขาย เช่น `2026-11-20T10:00:00+07:00` (ต้องมี `+07:00`)
2. กระเป๋ารับ vesting
3. กระเป๋าโครงการ
4. คีย์ของกระเป๋าที่ถือ IDTC (แบบซ่อน)

**สคริปต์จะทำตามลำดับ:**
1. ซ้อมทั้งสายบนเครื่อง: สร้างสัญญาจำลอง แล้วลองซื้อ 1 USDT
2. อ่านเชนจริง แล้วแสดงตัวเลขทุกบรรทัด โดยยังไม่ส่งอะไร
3. ให้พิมพ์ `IDTC` เพื่อยืนยัน
4. approve ยอดพอดี: 970B IDTC + 10 USDT_TPIX
5. จำลอง `createLaunch` ก่อน แล้วค่อยส่งจริงในธุรกรรมเดียว ซึ่งได้ทั้งสัญญาขาย PoolFeeder vesting และพูล IDTC/USDT ที่ราคาขาย
6. ตั้งซื้อขั้นต่ำ 1 USDT
7. ตรวจผลบนเชน แล้วพิมพ์ที่อยู่ Sale

**ข้อควรรู้:**
- หลังส่งแล้ว แก้ราคา จำนวน วันล็อก LP และ vesting ไม่ได้อีก
- รันซ้ำได้: ถ้าเปิดไปแล้ว สคริปต์จะแสดงสถานะ และไม่เปิดซ้ำ

## 7. 🤖 ลงทะเบียนหน้าขาย + เปิดระบบ

1. verify สัญญาขาย/feeder/vesting บน explorer
2. `php artisan launchpad:register <Sale>` แล้วสถานะจะเป็น pending
   - ระบบอ่านทุกค่าจากเชน ปฏิเสธเหรียญเสี่ยง และปฏิเสธสัญญาที่ไม่ได้มาจากโรงงาน
3. ตรวจที่ `/admin/launchpad`
4. ⛔ ตั้ง `LAUNCHPAD_ENABLED=true` แล้วรัน `config:cache`
   - ตรวจว่า scheduler รัน `launchpad:deliver` ทุกนาที
5. ⛔ อนุมัติหน้าขายที่ `/admin/launchpad` (หรือ `--approve`)
   - ลิงก์ "TPIX Launchpad" จะขึ้นในเมนู ส่วนท้ายเว็บ และแถบข้างเอง

## 8. 👤🤖 ซื้อทดสอบจริงหนึ่งครั้ง

**👤 เจ้าของ:**
1. ใช้กระเป๋าส่วนตัวใบอื่นที่มี USDT + BNB เล็กน้อยบน BSC
2. เข้า `tpix.online/launchpad/IDTC` แล้วซื้อ 1–2 USDT ตามคู่มือผู้ซื้อ (`BUYER-GUIDE-TH.md`)

**🤖 Claude ตรวจทีละขั้นบนเชน:**
1. ธุรกรรม USDT บน BSC เข้าคลังสะพาน
2. สะพานมิ้นต์ USDT_TPIX ให้กระเป๋าตัวแทน
3. ตัวแทนเรียก `buyFor` แล้ว IDTC เข้ากระเป๋าผู้ซื้อตามราคา
4. `feed()` ทำให้พูล IDTC/USDT โตขึ้น
5. หน้าเว็บแสดง "ได้รับเหรียญแล้ว"

ถ้าขั้นไหนไม่ผ่าน ให้หยุดขาย: **pause ทำผ่าน PoolFeeder `pauseSale()`** ด้วยกระเป๋าที่เปิดขาย หรือซ่อนหน้าขายในหลังบ้าน
