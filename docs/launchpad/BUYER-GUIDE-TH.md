# วิธีซื้อเหรียญบน TPIX Launchpad (ตัวอย่าง: IDTC)

จ่าย **USDT บน BSC** ครั้งเดียว แล้วรับเหรียญบน **เชน TPIX (4289)** ที่กระเป๋าเดิมของคุณ โดยอัตโนมัติ
ไม่ต้องย้ายเงินข้ามเชนเอง และไม่ต้องกดซื้อบนเชน TPIX

หน้าขาย: `https://tpix.online/launchpad` → เลือกเหรียญ

---

## ต้องมีอะไรบ้าง

1. **กระเป๋าของคุณเอง** เช่น MetaMask, Trust Wallet, OKX Wallet หรือ TPIX Wallet
   - ⚠️ **ห้ามโอนจากกระดานเทรด** (Binance, Bitkub ฯลฯ)
   - เพราะระบบส่งเหรียญกลับไปที่ "ที่อยู่ที่โอนมา" ถ้าโอนจากกระดาน เหรียญจะไปอยู่ที่กระเป๋าของกระดาน ไม่ใช่ของคุณ
2. **USDT บนเครือข่าย BSC (BEP-20)** ตามจำนวนที่จะซื้อ ขั้นต่ำ 1 USDT
3. **BNB เล็กน้อย** ไว้จ่ายค่าแก๊สบน BSC (ประมาณ 0.0005 BNB ก็พอ)

## ขั้นตอน

1. **เชื่อมกระเป๋า** ที่หน้าขาย
2. **ใส่จำนวน USDT** ที่จะซื้อ
   - หน้าเว็บจะคำนวณให้ว่าจะได้กี่เหรียญ เช่น IDTC: 1 USDT = 666,666.67 IDTC
3. **กด "ตรวจคำสั่งซื้อ"**
   - หน้าเว็บแสดงยอดที่ต้องโอน และที่อยู่ปลายทางของสะพาน
   - ฝากเข้าไม่มีค่าธรรมเนียมสะพาน
   - อ่าน "อ่านก่อนซื้อ" ให้จบ แล้วติ๊กยอมรับทั้ง 2 ช่อง
4. **กด "เซ็นคำสั่งซื้อ"** แล้วยืนยันในกระเป๋า
   - เป็นการเซ็นข้อความ ไม่ใช่ธุรกรรม จึงไม่เสียค่าแก๊ส
   - ข้อความระบุจำนวนและเวลาหมดอายุของคำสั่ง
5. **กด "โอน … USDT จากกระเป๋าของฉัน"** แล้วยืนยันในกระเป๋า
   - กระเป๋าจะสลับไปเครือข่าย BSC และโอน USDT **ตามจำนวนในคำสั่งเป๊ะ ๆ**
6. **รอ** ประมาณ 1–5 นาที
   - หน้าเว็บจะอัปเดตสถานะเอง: รอ USDT ของคุณ → ได้รับเงินแล้ว → **ส่งเหรียญแล้ว**
   - ปิดหน้าได้ กลับมาดูทีหลังที่ "คำสั่งซื้อของฉัน" ในหน้าขาย
   - ⚠️ หน้าเว็บขึ้นว่าโอนแล้ว = **อย่าโอนซ้ำ**

## เห็นเหรียญในกระเป๋า

- เหรียญอยู่บน **เชน TPIX** ที่อยู่เดียวกับกระเป๋าที่โอน USDT มา
- กระเป๋ายังไม่รู้จักเชน TPIX: กด "เพิ่ม TPIX ลงกระเป๋า" ที่เมนูของเว็บ
- เพิ่มเหรียญ: คัดลอก "สัญญาเหรียญ" จากหัวข้อ "สัญญาบน TPIX Chain" ในหน้าขาย แล้วนำเข้าเหรียญ (Import token) ในกระเป๋าบนเครือข่าย TPIX Chain
- ค่าแก๊สบนเชน TPIX เป็น 0

## กฎสำคัญ — ถ้าไม่ตรงกฎ จะได้ USDT_TPIX คืนแทนเหรียญ

| กรณี | ผลที่ได้ |
|---|---|
| โอน**ไม่ตรงจำนวน**ในคำสั่ง | ได้ USDT_TPIX เท่าที่โอนบนเชน TPIX |
| โอน**หลังคำสั่งหมดอายุ** (30 นาที) หรือหลังกดยกเลิก | ได้ USDT_TPIX |
| ขายหมด / หมดเวลาขาย / หน้าขายถูกหยุด ระหว่างรอ | ได้ USDT_TPIX คืนเต็มจำนวน |
| โอนจาก**เครือข่ายอื่น** (ไม่ใช่ BSC) หรือโอนเหรียญอื่น | ระบบรับไม่ได้ — อย่าทำ |
| โอนจาก**กระดานเทรด** | เงินไปอยู่ที่กระเป๋าของกระดาน — อย่าทำ |

**USDT_TPIX คืออะไร**
- USDT ที่อยู่บนเชน TPIX หนุนด้วย USDT จริงบน BSC แบบ 1:1
- ถอนกลับเป็น USDT บน BSC ได้ที่ `tpix.online/bridge`
- หรือใช้ซื้อเหรียญในพูลบนเชน TPIX ได้เลย

## คำเตือนความเสี่ยง (อ่านก่อนซื้อ)

- ศึกษาโครงการให้ดีก่อนลงทุน
- ราคาเหรียญขึ้นลงได้ และอาจลดลงเมื่อเหรียญที่ล็อกไว้ทยอยปลด
- โครงการอาจล้มเหลวได้
- แพลตฟอร์มไม่รับประกันผลตอบแทน
- ป้ายข้อมูลบนหน้าขายอ่านมาจากเชนจริง ใช้ช่วยตัดสินใจได้ แต่ไม่ใช่คำรับรองว่าปลอดภัย
  - เช่น เหรียญปิดการมิ้นต์เพิ่มไหม, LP ล็อกถึงวันไหน, ผู้สร้างถือกี่ %
- เห็นอะไรผิดปกติ กด **"แจ้งเหรียญนี้"** ที่หน้าขาย ทีมงานจะตรวจสอบ

- ติดต่อพร้อมแนบ **เลขธุรกรรม BSC (tx hash)** ที่ได้จากกระเป๋า
